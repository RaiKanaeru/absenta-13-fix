# Rencana Implementasi: Impor Jadwal Otomatis (Tanpa Ubah Skema)

## Batasan & Asumsi

- Tidak mengubah skema DB; tabel target `jadwal` tetap apa adanya (ruang diabaikan).
- Sumber kelas: kolom pertama tiap grup 3 baris pada sheet JADWAL.
- Jam mulai/selesai: slot tetap dari konfigurasi.
- Mapel: pakai alias/abbrev → mapping ke `mapel` via konfigurasi.

## File/Kode yang Ditambahkan/Diubah

- Tambah konfigurasi:
  - `backend/config/schedule-import.config.json` (hari, slot jam, opsi impor)
  - `backend/config/mapel-alias.json` (alias → `kode_mapel` atau `id_mapel`)
  - `backend/config/kelas-map.json` (opsional normalisasi nama kelas → `id_kelas` jika perlu)
- Tambah utilitas importer:
  - `backend/utils/scheduleImporter.js` (parser Excel/CSV, validator, transformer, upsert)
- Ubah server untuk endpoint impor:
  - `server_modern.js` (route `POST /api/import/jadwal` + upload, peran admin saja)
- (Opsional) Hook UI impor:
  - `src/components/ExcelImportView.tsx` untuk unggah file & tampilkan hasil dry-run

## Alur Teknis

1) Validasi & parsing file

- Terima 1 file Excel (.xlsx) atau paket 3 CSV.
- Pastikan sheet: MASTER GURU HARIAN, JAM GURU, JADWAL (atau nama yang dikonfigurasi).
- Bangun struktur data:
  - masterGuruMap: KODE → { nama_lengkap, nama_panggilan } (untuk validasi ringan)
  - jadwalGrid: representasi matriks JADWAL (kolom = hari+jam, baris berkelompok 3)

2) Build cache mapping dari DB & config

- guruByIdGuru: SELECT `id`, `id_guru`, `username`, `nama` FROM `guru`; key = `id_guru`.
- kelasByNama: SELECT `id_kelas`, `nama_kelas` FROM `kelas`; key = nama_kelas ternormalisasi.
- mapelByKode: SELECT `id_mapel`, `kode_mapel`, `nama_mapel` FROM `mapel`.
- aliasMap: dari `mapel-alias.json` → resolve ke `id_mapel` (via `kode_mapel`/`nama_mapel`).
- timeSlots: dari `schedule-import.config.json` (per hari, `jam_ke` → `jam_mulai/jam_selesai`).

3) Transform JADWAL → entri terstruktur

- Iterasi kolom: header → (hari, jam_ke).
- Iterasi baris per 3 (tiap grup = satu kelas):
  - `nama_kelas` = sel kolom pertama pada baris grup (A, A+1, A+2) → map ke `kelas_id`.
  - Baris-1: `kode_guru` cocok regex G\d+ → map ke `guru_id` via `guru.id_guru`.
  - Baris-2: `mapel_alias` → map ke `mapel_id` via `aliasMap`.
  - Baris-3: `ruang` (diabaikan, log sebagai info).
  - Build record: { kelas_id, hari, jam_ke, guru_id, mapel_id, jam_mulai, jam_selesai, status: 'aktif' }.
- Kumpulkan error bila mapping gagal (tanpa gagal total batch), kecuali opsi strict.

4) Upsert idempoten per kelas (transaksi per kelas)

- Kunci logis: (kelas_id, hari, jam_ke).
- Untuk setiap record:
  - SELECT 1 FROM `jadwal` WHERE kelas_id=? AND hari=? AND jam_ke=?
  - Jika ada → UPDATE `guru_id`, `mapel_id`, `jam_mulai`, `jam_selesai`, `status`.
  - Jika tidak ada → INSERT baru.
- Jalankan dalam TRANSACTION per `kelas_id` agar atomik.

5) Validasi silang (opsional, warning-only)

- JAM GURU vs hasil parse: total slot per guru per hari harus konsisten.
- MASTER GURU HARIAN: jika hari bertanda tidak tersedia namun mengajar, beri peringatan.

6) Endpoint & response

- `POST /api/import/jadwal` (role: admin): multipart upload, `?dryRun=true` untuk simulasi.
- Response JSON: ringkasan per kelas/hari/jam, inserted/updated/skipped/errors + warnings.
- Log file: `reports/import-schedule-YYYYMMDD-HHmmss.json`.

## Cuplikan Upsert (intisari)

```js
// Pseudocode ringkas
for (const entry of recordsByKelas[kelasId]) {
  await conn.beginTransaction();
  const exists = await conn.query(
    'SELECT id_jadwal FROM jadwal WHERE kelas_id=? AND hari=? AND jam_ke=? LIMIT 1',
    [entry.kelas_id, entry.hari, entry.jam_ke]
  );
  if (exists.length) {
    await conn.query(
      'UPDATE jadwal SET guru_id=?, mapel_id=?, jam_mulai=?, jam_selesai=?, status="aktif" WHERE id_jadwal=?',
      [entry.guru_id, entry.mapel_id, entry.jam_mulai, entry.jam_selesai, exists[0].id_jadwal]
    );
  } else {
    await conn.query(
      'INSERT INTO jadwal (kelas_id, mapel_id, guru_id, hari, jam_ke, jam_mulai, jam_selesai, status) VALUES (?,?,?,?,?,?,?,"aktif")',
      [entry.kelas_id, entry.mapel_id, entry.guru_id, entry.hari, entry.jam_ke, entry.jam_mulai, entry.jam_selesai]
    );
  }
  await conn.commit();
}
```
